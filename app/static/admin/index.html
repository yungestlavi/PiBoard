Come ottenere la chiave API di Google Drive

La chiave API serve solo a leggere una cartella che hai condiviso pubblicamente. È gratuita e non dà accesso al tuo account.

  1. Vai su console.cloud.google.com e accedi con un account Google.
  2. In alto, apri il selettore dei progetti e crea un Nuovo progetto (dagli un nome, es. PiBoard, e premi Crea).
  3. Vai su API e servizi → Libreria, cerca Google Drive API e premi Abilita.
  4. Vai su API e servizi → Credenziali → Crea credenziali → Chiave API.
  5. Copia la chiave che appare: inizia con AIza…
  6. (Consigliato) Clicca sulla chiave appena creata → Restrizioni API → seleziona solo Google Drive API → Salva.
  7. Incolla la chiave qui sopra nel campo Chiave API Google.

Ricorda: la cartella su Google Drive va condivisa come "Chiunque con il link → Visualizzatore", altrimenti la chiave non può leggerla.

⚠️ Non inserire qui un ID client OAuth (finisce con apps.googleusercontent.com): serve la Chiave API, quella che inizia con AIza…
